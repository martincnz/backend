# Modo Avión

Juegos para **el celular**. El motor valida automáticamente en el teléfono (sin depender de que el otro “te crea”).

Abrí la página en el teléfono, tocá **Jugar en este celular** y pásenselo. Si quieren tres teléfonos, mandales el mismo link: uno prende el hotspot, los otros se conectan a ese Wi‑Fi y escanean el QR.

Bluetooth entre navegadores no funciona entre celulares. El hotspot sí.

## Juegos

- **Pinturillo** — uno dibuja, los otros adivinan la palabra.
- **Gartic Phone** — teléfono descompuesto con dibujos + opciones.
- **Taboo** — elegís 3 claves y el motor valida “palabra prohibida”.
- **Adivina** — quiz de famoso/objeto/categoría con opciones.
