# Modo Avión

Juegos para **el celular**. El teléfono es el juez: cuenta toques, mide el temblor, lee la inclinación y toma el tiempo. No hay que “confiar” en el otro.

Abrí la página en el teléfono, tocá **Jugar en este celular** y pásenselo. Si quieren tres teléfonos, mandales el mismo link: uno prende el hotspot, los otros se conectan a ese Wi‑Fi y escanean el QR.

Bluetooth entre navegadores no funciona entre celulares. El hotspot sí.

## Juegos

- **Cinturón** — reacción. El reloj del celu decide.
- **Ventanilla** — uno dibuja, los otros adivinan.
- **Temblor** — sacudí el teléfono. El acelerómetro suma.
- **Piloto** — incliná y quedate en verde. Giroscopio.
- **Turbo** — toques. El teléfono cuenta.
- **Eco** — Simon: el celu muestra, vibra y valida.
